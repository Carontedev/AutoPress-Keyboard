AUTOPRESS KEYBOARD | 0.4.0-beta.1 | WINDOWS x64
https://github.com/Carontedev/AutoPress-Keyboard

GET STARTED
1. Extract the ZIP to a folder.
2. Open AutoPress.exe. No installer or separate .NET installation is needed.
3. Click Key and press the key you want to repeat.
4. Set Interval (ms). Example: 1000 means one press per second.
5. Press F8 to start the three-second countdown; press F8 again to stop.

EMERGENCY STOP: Ctrl + Alt + F10

Open settings to change the shortcut, select a startup application, or set
a duration/keystroke limit. Enable No limit to run until you stop it.
Input follows the active window. Changing windows DOES NOT stop automation.
A startup target is checked only when the countdown ends, not throughout
the session. Input is not sent to background applications.

Minimize sends the app to the system tray. Double-click its tray icon to
reopen it. Close or choose Exit in the tray menu to stop and exit.
If Release key appears, focus a non-elevated window and retry the release.

IMPORTANT
This is an unsigned evaluation beta. Windows may show an unrecognized-app
warning. Do not disable Windows or antivirus protections.
Some applications reject synthetic input. Game compatibility is not
guaranteed. No anti-cheat bypass or protection against bans is provided.
Use automation only where it is permitted.

Preferences: %LocalAppData%\AutoPressKeyboard\settings\settings.json
