# Bundled runtime notices

These unmodified texts are from the NuGet runtime packages used by the
Windows x64 self-contained build:

- `microsoft.netcore.app.runtime.win-x64/10.0.12`: LICENSE.TXT and THIRD-PARTY-NOTICES.TXT.
- `microsoft.windowsdesktop.app.runtime.win-x64/10.0.12`: LICENSE.

The minimal package appends these texts to README.txt. Update them when
upgrading the bundled runtime. They do not license AutoPress itself.
