# AutoPress Keyboard — Windows portable beta

## Download & run

Download **AutoPress-Keyboard-v0.4.0-beta.1-win-x64.zip** under Assets,
choose **Extract All**, then open **AutoPress.exe**.

The ZIP contains only:

- **AutoPress.exe** — standalone Windows x64 application; .NET is included.
- **README.txt** — quick start, shortcuts, limitations, and bundled runtime notices.

No installation or account is required. The **Source code** archives generated
by GitHub are for developers, not the ready-to-run application.

## Quick start

Select your key, set the interval, and press **F8** to start or stop.
**Ctrl + Alt + F10** is the emergency stop.

Input follows the active window; switching windows does not stop the session.

## Included

- Compact interface with native Windows controls, themes, and system tray.
- Click-to-capture key selection and configurable global toggle shortcut.
- Time, keystroke, and unlimited session modes.
- Application icon sizing fix and pending-key-release recovery.

## Before using

This is an **unsigned prerelease**, not a signed stable release. Windows may
display an unrecognized-app warning. Do not disable security protections.
Applications may reject synthetic input. Game compatibility and protection
against bans are not guaranteed; use automation only where permitted.

The project has no selected redistribution license. Bundled third-party
license notices are included in README.txt.
